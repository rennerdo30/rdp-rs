Privacy

This website

This site sets no cookies, uses no analytics and loads nothing from other sites except one request: your browser asks the public GitHub API for the newest Remora release, so the download buttons can link its files. GitHub receives that request like any other visit to GitHub. The site is hosted on GitHub Pages, which logs visitor IP addresses in its own server logs; see the GitHub privacy statement.

Remora

Remora has no account and no telemetry. It talks to the network for two things only:

  • Your connections. Remora connects to the servers you choose, directly or through the RD Gateway you set. What you share with a session (clipboard, folders, printers, smart cards, sound, microphone) goes only to that session, and only while its switch is on. When you sign in with Windows (Kerberos), Windows asks your domain controller for the ticket, as it does for any sign-in on your network.
  • Updates. A copy installed with the setup asks the public GitHub API once a day whether a newer Remora release exists. That request carries no information about you or your connections beyond what any web request does. When you install an update, Remora downloads the setup and its checksum file from GitHub. Portable copies never check, and Settings turns the daily check off.

Everything else stays on your PC: your connections and settings in %APPDATA%\rdp-rs, and licences, the bitmap cache and the diagnostic log in %LOCALAPPDATA%\rdp-rs. The diagnostic log is off unless you turn it on, and it never contains passwords. Nothing is uploaded on its own; a log reaches us only if you attach it to a bug report yourself.
