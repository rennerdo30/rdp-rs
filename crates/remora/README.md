# Remora

A remote desktop (RDP) client for Windows: every remote PC in one window,
each session in its own tab, with a connection manager, a command palette and
redirection of the clipboard, drives, printers, smart cards, sound and the
microphone. Built on [`rdp-proto`](https://crates.io/crates/rdp-proto).

```sh
cargo install remora-client
```

This installs the program `remora`. Remora is a Windows program today; the
setup and a portable zip are on
[GitHub Releases](https://github.com/rennerdo30/rdp-rs/releases), and the
website is [remora.renner.dev](https://remora.renner.dev).
